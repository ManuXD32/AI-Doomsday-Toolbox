# Implementation planning

Inspect the affected implementation and existing conventions before proposing work. Resolve important ambiguity with the question tool. Produce a plan that names behavior, data flow, migration needs, UI states, failure handling, tests, documentation, and release validation. Keep the plan actionable and avoid claiming unverified architecture.
