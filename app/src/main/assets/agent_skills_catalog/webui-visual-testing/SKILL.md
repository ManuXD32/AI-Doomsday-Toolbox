# WebUI visual testing

Observe before interacting. Perform one tap, key, text, scroll, wait, or reload action at a time, then observe again. Check loading, layout, clipping, focus, navigation, errors, and small viewport behavior. Report tested screens, actions, findings, and reproduction details without editing project files.
